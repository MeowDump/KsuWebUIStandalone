Standalone implementation of the [KernelSU WebUI](https://kernelsu.org/guide/module-webui.html)
### A personal KSU WebUI fork focused on convenience for Magisk users.

Normally, module management and WebUI access are handled by separate apps. If you need to run an action script, enable a module, or remove one, you have to open Magisk. If you want to access the module's WebUI, you have to switch back to the WebUI app.

This fork combines those common tasks into a single app, along with useful features and UI enhancements.

> [!IMPORTANT]
> If the original WebUI app is already installed, uninstall it before installing this fork. Installation will fail otherwise.
